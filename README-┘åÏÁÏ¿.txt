روزشمار شمسی — نسخه‌ی وب (PWA) برای آیفون — نسخه‌ی ۲.۷.۱
طراحی و توسعه : علی شکری
====================================================

این پوشه یک برنامه‌ی وب کامل است. برای این‌که روی آیفون «نصب» شود و بدون اینترنت هم کار کند،
باید یک بار روی یک آدرس HTTPS گذاشته شود (فایل را مستقیم از Files آیفون باز نکنید؛ آن‌طوری نصب نمی‌شود).

----------------------------------------------------
گذاشتن روی اینترنت با GitHub Pages (رایگان؛ GitHub برای کاربران ایران رسماً باز است)
----------------------------------------------------
راهنمای تصویری قدم‌به‌قدم همین مراحل جداگانه همراه برنامه است.
۱. فایل zip را روی کامپیوتر باز کنید (Extract All) تا پوشه‌ی RoozShomar-PWA ساخته شود.
۲. در github.com/signup یک حساب رایگان بسازید.
۳. دکمه‌ی + بالا ← New repository ← نام: roozshomar ← Public ← Create repository
۴. روی لینک «uploading an existing file» بزنید.
۵. پوشه‌ی RoozShomar-PWA را باز کنید، Ctrl+A بزنید و همه‌ی ۳۴ فایل را داخل کادر بکشید
   (یا روی «choose your files» بزنید و همه را انتخاب کنید)؛ بعد Commit changes.
   داخل این پوشه هیچ زیرپوشه‌ای نیست. خود فایل zip را بارگذاری نکنید؛ GitHub آن را باز نمی‌کند.
۶. Settings ← Pages ← Source: Deploy from a branch ← Branch: main و / (root) ← Save
۷. ۱ تا ۳ دقیقه بعد آدرس https://نام‌کاربری.github.io/roozshomar/ آماده است.

(هر میزبان دیگری که HTTPS دارد هم کار می‌کند؛ فقط همه‌ی فایل‌ها کنار هم بمانند.
 Netlify مناسب نیست: برای کاربران ایران ثبت‌نام نمی‌دهد و سایت بدون حساب بعد از یک ساعت پاک می‌شود.)

----------------------------------------------------
نصب روی آیفون
----------------------------------------------------
۱. آدرس را در Safari باز کنید.
۲. iOS 26 به بعد: دکمه‌ی ••• کنار آدرس ← Share ← Add to Home Screen ← Open as Web App روشن ← Add
   iOS 18 و قدیمی‌تر: دکمه‌ی اشتراک‌گذاری (مربع با فلش رو به بالا) ← Add to Home Screen ← Add
۳. آیکون «روزشمار» روی صفحه‌ی اصلی می‌آید و مثل یک برنامه‌ی معمولی، تمام‌صفحه و بدون اینترنت باز می‌شود.

----------------------------------------------------
درباره‌ی ویجت
----------------------------------------------------
اپل به برنامه‌های وب (PWA) اجازه‌ی ساختن ویجت صفحه‌ی اصلی را نمی‌دهد؛ ویجت واقعی آیفون فقط با
یک برنامه‌ی بومی (Swift، از طریق App Store یا TestFlight) ساخته می‌شود.
به‌جای آن «صفحه‌ی امروز» ساخته شده که همان کار صفحه‌ی ویجت اندروید را می‌کند:
  • تاریخ امروز شمسی، میلادی و قمری، تقویم ماه، مناسبت‌ها
  • شیشه‌ای با شفافیت قابل تنظیم، رنگ شیشه‌ی تیره یا روشن
  • امکان گذاشتن تصویر پس‌زمینه‌ی گوشی پشت آن (تا مثل ویجت روی والپیپر دیده شود)
  • جابه‌جایی بخش‌ها با نگه داشتن انگشت و کشیدن
برای این‌که با یک لمس باز شود، آن را جداگانه نصب کنید:
  آدرس اصلی/today.html را در Safari باز کنید ← اشتراک‌گذاری ← Add to Home Screen
  آیکون جداگانه‌ی «امروز» کنار آیکون روزشمار قرار می‌گیرد.
نکته: آیفون حافظه‌ی هر آیکون نصب‌شده را جدا نگه می‌دارد؛ اگر تم را در روزشمار عوض کردید،
در آیکون «امروز» هم از ⚙ ← «رنگ و تم برنامه» یک بار انتخابش کنید.

----------------------------------------------------
امکانات (هم‌سطح نسخه‌ی اندروید ۲.۷.۱)
----------------------------------------------------
محاسبه با روز / هفته / ماه، روزهای کاری (بدون جمعه و تعطیلات رسمی) با گزینه‌ی پنج‌شنبه،
تاریخ میلادی و قمری، تقویم با انتخاب سریع سال و ماه، مناسبت‌ها (۱۴۰۰ تا ۱۴۱۱ داخل برنامه)،
اشتراک‌گذاری، یادآور (افزودن به تقویم آیفون)، سابقه‌ی ۳۰ محاسبه، فاصله‌ی دو تاریخ، محاسبه‌ی سن،
۱۶ تم رنگی + رنگ دلخواه، راهنما.

به‌روزرسانی: در مخزن GitHub ← Add file ← Upload files ← فایل‌های جدید را بکشید ← Commit changes؛
آیفون‌ها در باز شدن بعدی (گاهی یک بار بستن و باز کردن دوباره) نسخه‌ی جدید را می‌گیرند.
